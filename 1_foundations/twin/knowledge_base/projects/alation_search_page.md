# Alation Search Page Redesign

## Summary
At Alation, there was a period when the Search team needed more frontend developer capacity to ship a new search page redesign. Ralph Arroyo felt he would not be able to contribute as much during that period, so he learned React and Redux in order to make frontend contributions.

## Contributions
He started with simpler tasks that involved minor frontend changes. He later made more significant contributions:

- He became a regular reviewer of frontend code for his peers.
- He introduced a performance-oriented refactor that eliminated redundant component rerenders.
- He proposed and implemented changes across both the backend and the frontend so the team could track Search performance metrics, such as click relevancy, and measure search quality and user engagement across different versions.

## Scope of frontend expertise
Ralph would not describe himself as a React or Redux expert. He learned those tools as he went, at a time when the team needed more people who could work on the frontend.
