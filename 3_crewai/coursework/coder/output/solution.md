I wrote a Python program in `leibniz_pi.py` to calculate the first 1,000,000 terms of the Leibniz series:

`1 - 1/3 + 1/5 - 1/7 + ...`

The program uses Python’s `decimal` module for higher precision, sums 1,000,000 terms, and multiplies the result by 4.

Final output from running the script:

`3.1415916535897932387126433832791903841971703525036`
